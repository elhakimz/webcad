
# WebCAD Scaffold

A minimal AutoCAD 2.18-style web CAD prototype using Three.js.

## Features (MVP)
- Command line input
- LINE command (2-point drawing)
- Basic Three.js rendering
- DOS-style black UI

## Install

```bash
npm install
npm run dev
```

## Usage

1. Type command:
```
LINE
```

2. Click first point
3. Click second point → line is drawn
