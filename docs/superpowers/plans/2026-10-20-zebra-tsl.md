# TSL Zebra Port Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the inline GLSL zebra shader with one TSL node material that renders identically on the current WebGL renderer and is ready for `WebGPURenderer` in #169.

**Architecture:** `src/render/ZebraMaterial.ts` owns the only zebra definition (`MeshBasicNodeMaterial` + TSL) and installs three's `WebGLNodesHandler` compatibility builder on the classic renderer. `Viewer` keeps returning the shared material from `getMeshMaterial('ZEBRA')`; the GLSL block is deleted. Golden screenshots captured from the GLSL build are the regression oracle.

**Tech Stack:** three 0.185.1, TSL (`three/tsl`), `three/webgpu`, `WebGLNodesHandler`, Playwright, Vitest.

**Spec:** `docs/superpowers/specs/2026-10-20-zebra-tsl-design.md`

## Global Constraints

- three is pinned at 0.185.1; the node system is a **static** import (approved), not lazy.
- One zebra definition only. No GLSL fallback, no second code path.
- Preserve the exact stripe math: `reflect(normalize(positionView), normalView)`, `sin((y + x*0.3) * 30)`, `step(0, signal)`.
- Do **not** substitute `positionViewDirection`: the viewport camera is orthographic and TSL returns a constant `(0,0,1)` there, which changes the stripes.
- Baselines are recorded **before** the port, on the GLSL build, and the TSL port must match at `maxDiffPixelRatio: 0.01`.
- No CI. Every gate is a local command.
- Never print, echo, or commit the Plane token in `plane-secret-key.csv`.
- Do not commit workspace noise: `files/TEST.dxf`, `test-results/`, `.wolf/`, `.claude/`, `CLAUDE.md`.

## Review Focus

- Leaving ZEBRA must restore each solid's original colour, not white (`MeshBasicNodeMaterial.color` exists, unlike `ShaderMaterial`).
- Stripes must stay continuous across curved fillets and cylinder walls (normal transform).
- Selecting a solid while in ZEBRA must not replace the zebra material or break selection.
- Resizing the viewport in ZEBRA must leave the mode and edges intact.
- Entering ZEBRA with an empty scene must not crash or block returning to SHADED.

Create `src/render/ZebraMaterial.ts`:

```ts
import * as THREE from 'three'
import { MeshBasicNodeMaterial } from 'three/webgpu'
import { WebGLNodesHandler } from 'three/examples/jsm/tsl/WebGLNodesHandler.js'
import { normalView, positionView, reflect, sin, step, vec3 } from 'three/tsl'

const ZEBRA_FREQUENCY = 30

/**
 * The only zebra definition (WEBCAD-166).
 *
 * Translation of the old GLSL:
 *   viewDir    = normalize(-mvPosition.xyz)   -> positionView.normalize()
 *   reflectDir = reflect(-viewDir, normal)    -> reflect(incident, normalView)
 *   stripe     = step(0, sin((r.y + r.x*0.3) * 30))
 *
 * `positionViewDirection` is deliberately not used: the viewport camera is
 * orthographic, where TSL returns a constant (0,0,1) instead of the
 * per-fragment vector the old shader used.
 */
export function createZebraMaterial(): MeshBasicNodeMaterial {
  const material = new MeshBasicNodeMaterial({ side: THREE.DoubleSide })
  material.name = 'ZebraSurface'

  const incident = positionView.normalize()
  const reflected = reflect(incident, normalView)
  const signal = sin(reflected.y.add(reflected.x.mul(0.3)).mul(ZEBRA_FREQUENCY))
  material.colorNode = vec3(step(0, signal))

  return material
}

/**
 * Teach a classic WebGLRenderer to build TSL node materials. A future
 * WebGPURenderer needs no handler and never calls this.
 */
export function enableNodeMaterials(renderer: THREE.WebGLRenderer): void {
  renderer.setNodesHandler(new WebGLNodesHandler())
}
```

```ts
import * as THREE from 'three'
import { WebGPURenderer } from 'three/webgpu'
import { RoundedBoxGeometry } from 'three/examples/jsm/geometries/RoundedBoxGeometry.js'
import { createZebraMaterial, enableNodeMaterials } from '../../src/render/ZebraMaterial'

function createPane() {
  const scene = new THREE.Scene()
  scene.background = new THREE.Color(0x0e1216)

  const geometry = new RoundedBoxGeometry(2, 2, 2, 6, 0.35)
  scene.add(new THREE.Mesh(geometry, createZebraMaterial()))

  const camera = new THREE.PerspectiveCamera(40, 1, 0.1, 100)
  camera.position.set(3.4, 2.6, 3.8)
  camera.lookAt(0, 0, 0)

  return { scene, camera }
}

async function main() {
  const glCanvas = document.querySelector<HTMLCanvasElement>('#webgl')!
  const gpuCanvas = document.querySelector<HTMLCanvasElement>('#webgpu')!
  const status = document.querySelector<HTMLElement>('#status')!
  const gpuCaption = document.querySelector<HTMLElement>('#webgpu-caption')!

  const glPane = createPane()
  const glRenderer = new THREE.WebGLRenderer({ canvas: glCanvas, antialias: true })
  glRenderer.outputColorSpace = THREE.SRGBColorSpace
  enableNodeMaterials(glRenderer)

  const gpuPane = createPane()
  const gpuRenderer = new WebGPURenderer({ canvas: gpuCanvas, antialias: true })
  await gpuRenderer.init()
  gpuRenderer.outputColorSpace = THREE.SRGBColorSpace

  const isWebGPU = (gpuRenderer.backend as { isWebGPUBackend?: boolean }).isWebGPUBackend
  gpuCaption.textContent = isWebGPU ? 'WebGPURenderer (WebGPU backend)' : 'WebGPURenderer (WebGL 2 fallback)'

  const resize = (renderer: THREE.WebGLRenderer | WebGPURenderer, canvas: HTMLCanvasElement) => {
    const width = Math.max(1, canvas.clientWidth)
    const height = Math.max(1, canvas.clientHeight)
    renderer.setPixelRatio(window.devicePixelRatio)
    renderer.setSize(width, height, false)
  }

  const draw = () => {
    resize(glRenderer, glCanvas)
    resize(gpuRenderer, gpuCanvas)

    glPane.camera.aspect = glCanvas.clientWidth / Math.max(1, glCanvas.clientHeight)
    glPane.camera.updateProjectionMatrix()
    gpuPane.camera.aspect = gpuCanvas.clientWidth / Math.max(1, gpuCanvas.clientHeight)
    gpuPane.camera.updateProjectionMatrix()

    glRenderer.render(glPane.scene, glPane.camera)
    void gpuRenderer.renderAsync(gpuPane.scene, gpuPane.camera)
  }

  window.addEventListener('resize', draw)
  draw()

  status.textContent = isWebGPU ? 'WebGPU backend active' : 'WebGPU unavailable — three fell back to WebGL 2'
  document.body.dataset.parityReady = 'true'
}

main().catch((error) => {
  console.error(error)
  document.querySelector('#status')!.textContent = `failed: ${String(error)}`
})
```
